Solana wallets

Voeg publieke Solana-adressen toe. SOL-saldo + USD-waarde via publieke RPC en CoinGecko-koers.

Polygon wallets

Voeg publieke Polygon (MATIC/POL) adressen toe. Native saldo via publieke RPC.

Bybit

Unified Trading Account saldo, via serverless proxy (/api/bybit). API key nodig met minstens "read" rechten op account info.
Binnenkort

Ledger cold storage-integratie komt hier. Adressen die je via je Ledger beheert kan je trouwens nu al toevoegen onder Solana / Polygon als publiek adres — enkel het rechtstreeks verbinden met het apparaat (WebUSB/WebHID) volgt later.

API-toegang

Deze gegevens blijven uitsluitend in de localStorage van jouw browser op dit toestel — nooit in code, nooit in git, nooit op GitHub. Ze worden enkel per aanvraag meegestuurd naar de serverless functie om de call uit te voeren, en daar niet bewaard.
